How to use Lore for this

  1. Start with one thing you would tell a friend.
  2. Add text, a photo or voice; expand it only if you want to.
  3. Tap Save and wait for confirmation before the weekly deadline.

Questions before you start

Does every update need a photo?

No. A text update can stand on its own.

Can I keep adding things through the week?

You can edit your own update while the week is open. In the current beta, save your changes explicitly.

Will closing the editor share unfinished work?

Closing can keep private work on your phone. It does not turn an unconfirmed draft into a shared submission.
